# Security policy

## Reporting a vulnerability

Do not disclose a security issue, credential, personal-data exposure, or unsafe corpus record in a public issue.

Use GitHub's **Security → Report a vulnerability** flow for this repository. If private vulnerability reporting is unavailable, contact the maintainer through the GitHub profile [`@nik1t7n`](https://github.com/nik1t7n) without including sensitive details in public.

Include the affected revision, the smallest reproduction, expected impact, and whether the report involves data that should not be copied. Reports about upstream datasets or dependencies may need to be coordinated with their original maintainers.

Only the current `main` branch is supported. No security guarantees are made for locally generated corpora, modified configurations, or downstream language models built from this research code.
